# Sistema de ventas - Spring Boot

## 📌 Descripción
Aplicación web para la gestión de productos con autenticación y control de roles.

## 🚀 Tecnologías
- Java
- Spring Boot
- MySQL
- Thymeleaf
- Bootstrap

## 🔐 Funcionalidades
- Login de usuarios
- Roles ADMIN / USER
- CRUD de productos
- Validaciones
- Seguridad con Spring Security
